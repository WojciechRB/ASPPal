# ASPPal
A minimal ASP.NET Core web app that returns "Hello World!" at the root URL.

> **Note:** This README was generated by Claude, an AI assistant made by Anthropic.

## Prerequisites

- [.NET SDK](https://dotnet.microsoft.com/download) (check with `dotnet --version`)

## Option 1: Command line

```bash
dotnet new web -n HelloWorld
cd HelloWorld
dotnet run
```

When the app starts, it prints a local address such as `http://localhost:5000`. Open it in a browser to see the message.

## Option 2: Visual Studio 2022 (or newer)

1. Select **Create a new project** from the start window.
2. Search for **ASP.NET Core Empty**, select it, and click **Next**.
3. Name the project (e.g. `HelloWorld`) and click **Next**.
4. Pick your .NET version, leave the other options at their defaults, and click **Create**.
5. Press **Ctrl+F5** (run without debugging) or **F5** (with debugging).

The browser opens automatically and shows "Hello World!".

If you don't see the template, open the Visual Studio Installer, click **Modify**, and install the **ASP.NET and web development** workload.

## Program.cs

Both options generate the same code:

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/", () => "Hello World!\n");

app.Run();
```
